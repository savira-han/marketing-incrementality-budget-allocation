# Marketing Incrementality & Budget Allocation

## Objective

Evaluates marketing incrementality, customer economics, marginal returns, and optimal allocation of an additional $2M marketing budget.

## Core Question

> Where should we invest the additional $2M, and how much incremental contribution margin should we expect?

## Analytical Framework

Measurement
→ Attribution
→ Incrementality
→ Customer Economics
→ Marginal Returns
→ Budget Optimization
→ Executive Decision
